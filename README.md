# Fossil Sort（仮）

岩の柱に積まれた色の石を移して、**縦に4つ・横に3本**そろえて消すパズル。消えると上の石が沈み、またそろえば連鎖する。5ステージごとに、柱の底に埋まった化石を掘り出すステージが来る。

型は [web-game-template](https://github.com/pupe-xxx/web-game-template)（TypeScript + Vite + Canvas）。ステージ制の外枠（`src/ui/shell.ts`）は ROLLER BREAK から持ってきた。

## ルール

- 柱は最大 5 段。柱をタップして選び、移す先をタップする。上の同じ色はまとめて移り、入りきらない分は元の柱に残る。置けるのは空の柱か、同じ色の石の上だけ
- **縦**：1本の柱のどこでも、同じ色が4つ続くと消える
- **横**（ステージ 11 から）：同じ高さで、隣り合う3本以上の柱が同じ色だと消える
- その時そろっている物を縦も横もいっしょに消す → 上の石が沈む → またそろえば連鎖
- **化石**（ステージ 5・10・15・20）：柱の底の1段を使う、動かせない石。上に石は置けない。上の石を全部どかすと掘り出す。手数に上限があり、全部掘ればクリア（石は残ってよい）
- 普通のステージは石を全部消せばクリア。最少の手数で★3

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす（全ステージが開いている。鍵を見たい時は `?lock`、ヒントを何度でも使うには `?help`） |
| `npm test` | ルールのテスト・速い探索とルールの照合・全ステージが記録の手数で解けるか・動作記録 |
| `npm run gen` | ステージを作り直す（`npm run gen -- 12` で 12 番だけ）。`src/game/levels.gen.ts` に書く |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す。ルールかステージを変えた時だけ |
| `npm run typecheck` / `npm run build` | 型の検査 / 公開用のファイルを作る |

## フォルダ

```
src/
  game/
    rules.ts       ルール（移す・消える・沈む・掘る・クリアと失敗）
    solve.ts       最少の手数を探す（柱を文字列で持つ速い版。ステージ作りとヒントに使う）
    levels.ts      ステージの一覧と深さ
    levels.gen.ts  npm run gen が作ったステージ（手で直さない）
  ui/
    shell.ts       ステージ制の外枠（ステージ選択・結果・ルールブック・ヒント・1手戻す）
    game.ts        この盤の描き方・タップ・動き・ルールブックの中身
  kit/           型の共通部分
scripts/gen.ts   ステージを作って総当たりで確かめる
```

## ステージの作り方

`scripts/gen.ts` が、でたらめに石を配った盤を総当たりで解き、次を満たすものだけを残す。

- 最少の手数が、ステージごとの幅に入る
- 空の柱は、どれを取り除いても最少では解けない
- 横のステージは、横で消えないと最少では解けない
- 連鎖・縦を使わせるステージは、最少の手順の中で起きる
- 条件を満たした中から、でたらめに打った時にクリアできる割合が一番低いものを選ぶ

柱が 7 本・石が 20 個を超えると、総当たりが重くなる（1ステージに数分〜十数分）。
