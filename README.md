# Fossil Sort（仮）

高さの違う柱でできた地層の、**段を1つ選んで左右にずらす**パズル。ずれた所から石が崩れ落ち、色が3つそろえば消えて連鎖し、奥に埋まった化石が姿を現す。1ステージは2〜6手の読み切り。

型は [web-game-template](https://github.com/pupe-xxx/web-game-template)（TypeScript + Vite + Canvas）。ステージ制の外枠（`src/ui/shell.ts`）は ROLLER BREAK から持ってきた。

## ルール

- 1手：段を横になぞるか、段の両端の矢印を押すと、その段だけが1マスずれる。端から出た石は反対の端に入る。ずれた段の上の石は自分の柱に残る
- ずらした後、下が空いた石は真下に落ちる
- 縦か横に同じ色が3つ以上並ぶと消える（横は端をまたがない）。消えた所に上が落ち、またそろえば連鎖
- 化石は段と一緒にずれて落ちる。消えない。上に何も無くなったら掘り出す
- 目標はステージごとに1つ（全部消す／化石を掘り出す／〇連鎖させる）。決まった手数ちょうどで果たす。星は無い

## コマンド

| コマンド | すること |
|---|---|
| `npm run dev` | 手元で動かす（全ステージが開いている。鍵を見たい時は `?lock`、ヒントを何度でも使うには `?help`） |
| `npm test` | ルールのテスト・速い探索とルールの照合・全ステージが決まった手数で解けてそれより短く解けないか・動作記録 |
| `npm run gen` | ステージを作り直す（`npm run gen -- 12` で 12 番だけ）。`src/game/levels.gen.ts` に書く |
| `npm run record` | 動作記録（`tests/golden/golden.json`）を取り直す。ルールかステージを変えた時だけ |
| `npm run typecheck` / `npm run build` | 型の検査 / 公開用のファイルを作る |

## フォルダ

```
src/
  game/
    rules.ts       ルール（ずらす・落ちる・消える・掘る・目標）
    solve.ts       最少の手数を探す・でたらめに打った時に解ける確率（柱を文字列で持つ速い版）
    levels.ts      ステージの一覧と深さ
    levels.gen.ts  npm run gen が作ったステージ（手で直さない）
  ui/
    shell.ts       ステージ制の外枠。なぞる操作（drag）・星を使わない（starless）・ルールブックを自動で開かない（autoRules）を足した
    game.ts        この盤の描き方・なぞる／矢印・動き・ルールブックの中身
  kit/           型の共通部分
scripts/gen.ts   ステージを作って総当たりで確かめる
```

## ステージの作り方

`scripts/gen.ts` が、でたらめに石を配った盤を総当たりで解き、次を満たすものだけを残す。

- 決まった手数ちょうどで目標を果たせ、それより少ない手数では果たせない
- 教えている要素（崩れて縦でそろう・連鎖）が、最少の手順の中で起きる
- 打てる手から毎回でたらめに選んだ時に解ける確率が、ステージごとの上限以下
- 条件を満たした中から、その確率が一番低いものを選ぶ
